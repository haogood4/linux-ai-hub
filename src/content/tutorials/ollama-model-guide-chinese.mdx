## 问题现象

已经运行过 Ollama，但默认模型的中文回答生硬、答非所问。想换成中文能力更强的模型，却不知道模型名、tag、显存要求和切换方法。

## 根本原因

Ollama 本身只是模型运行工具，回答质量主要取决于模型。切换模型不需要重装 Ollama，只需拉取并运行另一个模型；多个模型可以同时保存在本地。

## 解决方案

### 1. 直接运行并切换模型

`ollama run` 会检查本地是否已有模型：有则直接启动，没有则自动下载。

运行 Qwen2.5 7B：

```bash
ollama run qwen2.5:7b
```

切换到 Qwen3 8B：

```bash
ollama run qwen3:8b
```

进入对话后输入问题即可。退出当前模型：

```text
/bye
```

也可以按 `Ctrl+D`。退出只会结束会话，不会删除模型。

### 2. 先下载，再运行

网络不稳定或想提前准备模型时，使用 `pull`：

```bash
ollama pull qwen2.5:7b
```

下载完成后运行：

```bash
ollama run qwen2.5:7b
```

查看本地模型库：

```bash
ollama list
```

查看正在占用内存或显存的模型：

```bash
ollama ps
```

停止后台模型：

```bash
ollama stop qwen2.5:7b
```

删除不再使用的模型：

```bash
ollama rm qwen2.5:7b
```

### 3. 中文模型怎么选

下表显存为常见 Q4 量化模型的实用估算，还需给上下文缓存预留空间。不同量化版本、上下文长度和硬件会影响实际占用。

| 模型名 | 适用场景 | 参数规模 | 建议显存 | 运行命令 |
|---|---|---:|---:|---|
| Qwen2.5 | 中文问答、写作、翻译、代码 | 7B | 6GB 起 | `ollama run qwen2.5:7b` |
| Qwen2.5 | 更复杂的写作、知识问答 | 14B | 12GB 起 | `ollama run qwen2.5:14b` |
| Qwen3 | 中文对话、推理、代码 | 8B | 8GB 起 | `ollama run qwen3:8b` |
| Qwen3 | 较复杂推理和长文本 | 14B | 12GB 起 | `ollama run qwen3:14b` |
| DeepSeek-R1 | 数学、逻辑、分步推理 | 7B | 6GB 起 | `ollama run deepseek-r1:7b` |
| DeepSeek-R1 | 更强推理，速度较慢 | 14B | 12GB 起 | `ollama run deepseek-r1:14b` |
| GLM-4 | 中文对话、摘要、办公文本 | 9B | 8GB 起 | `ollama run glm4:9b` |
| MiniCPM-V | 中文图片理解、OCR、视觉问答 | 8B | 8GB 起 | `ollama run minicpm-v:8b` |

只有 6GB 至 8GB 显存时，优先选 7B/8B；12GB 至 16GB 可尝试 14B。没有独立显卡也能使用 CPU 和内存运行，但速度通常较慢。72B 等大模型通常需要多卡或大量统一内存，不适合作为普通电脑的首选。

## 验证是否解决

先用同一道题对比两个模型：

```bash
ollama run qwen2.5:7b
```

输入：

```text
请用不超过150字解释“机会成本”，给出一个买电脑的例子，不要使用英文。
```

重点检查：是否全程中文、是否遵守字数、概念是否准确、例子是否贴合。

再测试指令执行和信息提取：

```text
把下面内容整理成“问题、原因、解决办法”三项，只能依据原文，不要补充信息：服务器磁盘使用率达到95%，日志目录占用800GB，旧日志没有按计划清理。
```

若模型频繁遗漏限制，可尝试 14B；若主要任务是数学和逻辑推理，可换 DeepSeek-R1。运行 `ollama ps` 可确认实际加载的模型。

**换模型口诀：先 `pull`，再 `run`；用 `list` 查看，用 `stop` 释放，用 `rm` 删除。**

## 常见问题 FAQ

### 模型名里的 tag 是什么？

tag 用来指定模型版本、参数规模或量化方式。`qwen2.5:7b` 中的 `7b` 表示约 70 亿参数；不写 tag 时通常使用 `latest`，例如 `qwen2.5` 等价于仓库当前默认版本。

`q4_K_M` 表示一种 4-bit 量化方案，体积和资源占用较低。完整 tag 可能类似 `7b-instruct-q4_K_M`，但并非每个模型都提供同名 tag，应以 Ollama 模型库页面列出的标签为准。

### 怎么查找更多模型？可以用 `ollama search` 吗？

当前常用 Ollama CLI 没有 `ollama search` 命令。请在 [Ollama Models](https://ollama.com/library) 搜索模型，确认名称和 tag 后再运行：

```bash
ollama pull qwen3:8b
```

### 换模型会删除旧模型吗？

不会。运行新模型只会切换当前会话，旧模型仍保存在本地，可通过 `ollama list` 查看。只有执行 `ollama rm` 才会删除。

### 模型存在哪里？

默认目录通常是：

- Linux：`~/.ollama/models`
- macOS：`~/.ollama/models`
- Windows：`%USERPROFILE%\.ollama\models`

可通过 `OLLAMA_MODELS` 环境变量修改存储位置。部署和目录配置详见 [Ollama 本地部署教程](/tutorials/ollama-local-deploy)。
